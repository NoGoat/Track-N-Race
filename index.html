Highlights

05 features

Session Files

Every session is saved as one .tnrd file, split by driver, by lap and by data type. Charts read only the blocks they need instead of the whole recording.

  • One file per session, every driver and every lap
  • Each driver, lap and data type is its own compressed block
  • Charts load only the blocks they need
  • Share it and compare laps against a friend's file in Analyze

Deep Analysis

Dive deep into your race data. Compare any data of your choosing either your own laps or against rivals or laps from an older session to find out what's costing you time.

  • Trace charts for almost any data
  • Compare against other drivers
  • Lap overlay comparisons
  • Customizable colors and chart hierarchy
  • Visualize your position on the map
Expand Image

Driver Selector

View every other driver's data and compare almost* every data channel to your own.

  • Select any driver in the session
  • Compare their data^ against your own

*The game does not expose ride height data for other drivers. Ride height will be unavailable for other drivers.

^Some data channels will be unavailable if the other driver has set their telemetry to restricted during online play.

Expand Image

Track almost Everything

Track N Race tries to track as much information as possible from the apps. Everything from tyres to ride heights can be tracked.

  • Record everything for future analysis
  • Replay recordings like a video
  • Includes track maps for almost* every circuit

*I do not own F1 24. So I couldn't get maps for any tracks exclusive to F1 24.

Expand Image

Minimal Recorder

Worried about performance penalties from running the app while playing the game? You can instead run the minimal recording and view your stats later in the main app.

  • Full data logging
  • Supports UDP forwarding
  • Minimal performance overhead
