Telemetry Setup Guide

Configure your game settings in minutes to start recording live telemetry data from F1 24, F1 25, and 2026 season DLC.

01

Enable Game Telemetry

Launch your F1 game (F1 24 / F1 25). Navigate to Game Options → Settings → Telemetry Settings.

Setting Value
UDP Telemetry On
UDP Broadcast Mode Off
02

Port & IP Configuration

Set up the target IP address and listening port so telemetry packets reach Track-N-Race.

Parameter Target Value
UDP IP Address 127.0.0.1 (or PC IP)
UDP Port 20777
UDP Send Rate 60Hz (Recommended)
03

UDP Format Selection

Ensure the UDP Format in settings matches your game version for precise packet parsing.

Game Version UDP Format
F1 25 / 2026 DLC 2025 (or 2024)
F1 24 2024
Console / Second PC Setup: If playing on PlayStation / Xbox or a dedicated rig PC while running Track-N-Race on a separate machine, set UDP Broadcast Mode to On or enter your PC's local IP address (e.g. 192.168.1.X) in the game UDP IP field, and make sure UDP Port 20777 is allowed through your Windows Firewall.
