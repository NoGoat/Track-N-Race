# Contributing to Track N Race

Thanks for your interest in Track N Race!

## Code contributions

Unfortunately, I don't accept code contributions. This is mainly due to Track N Race being
both a playground of sorts and a stress relief for me. Pull requests will be closed without
merging.

## Feedback and advice

Feedback and advice are welcome. If you've found a bug, have an idea for a feature, or think something could be done better, [open an issue](https://github.com/NoGoat/Track-N-Race/issues). Bug reports are most useful when they include:

- which app you're using (desktop or Android) and its version
- which game you were playing (F1 24, F1 25, etc.)
- what you expected to happen and what happened instead
- screenshots or a recording (`.tnrd`) if you have them

For security issues, see [SECURITY.md](SECURITY.md) instead.

## Forking

If you want to play around with the code, go ahead and fork it. Forks are welcome.

If you do fork it, let me know on [Discord](https://discord.gg/UMVRrN3RbR). I'd love to see what cool things you're doing with the codebase.

Forks have to follow the terms of the [GPLv3 License](LICENSE).
