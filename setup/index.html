Telemetry setup guide

Follow these steps to set up the game to send its telemetry data to Track N Race.

01

Turn On Telemetry

Launch your game and navigate to Settings → Telemetry Settings. Configure the following broadcast options:

02

Set Protocol Format

Set the UDP format to match what is supported by your game. For the best experience, use the highest possible version supported by both the game and the app.

03

Set UDP Port

In the in-game Telemetry Settings, set the UDP Port to match the value configured in the Track N Race application.

UDP Port Track N Race listens on port 20777 by default. If you configured a custom port inside Track N Race settings, enter that exact port number in the game.

Find the IP address of your second system

Option A • Command Line (Fastest)

Press Win + R, type cmd or open PowerShell, then run:

ipconfig

Look for IPv4 Address under your active connection (e.g. 192.168.1.150).

Option B • Windows Settings

Open Settings → Network & internet → click Wi-Fi or Ethernet → scroll down to Properties to view the IPv4 address.

Option A • System Settings

Click the Apple menu () → System Settings → Network → select your connected network (Wi-Fi or Ethernet) → click Details... to view your IP Address.

Option B • Terminal

Open Terminal and run the command for your active interface:

ipconfig getifaddr en0

Use en0 for Wi-Fi or en1 for Ethernet.

Terminal

Open your terminal and run:

hostname -I

Connection & firewall tips
  • Same Local Subnet: When using dual systems (e.g. gaming PC / console + secondary laptop / Mac), ensure both devices are connected to the same local network subnet (router/Wi-Fi).
  • Firewall Inbound Rule: Ensure inbound UDP traffic on port 20777 is permitted in your firewall settings on the machine running Track N Race.
